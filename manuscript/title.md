# The Harness Era

A plain-language tour of how chatbots became agents — and why the model is only half the product.

**Agent = Model + Harness**

If you have used ChatGPT, Claude, or Gemini, you have already met a **model**: software that predicts the next bit of text. This book is about everything around that model — memory, tools, sandboxes, and brakes — that you need before you can trust it to act.

You do not need a machine-learning background. Technical words show up with a definition the first time, then we use them.
